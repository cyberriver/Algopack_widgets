# FUTOI: продолжение и ложный пробой — ТЗ v0.1

Статус: исследовательский проект. Исторические данные не загружены, доходность не рассчитана. Параметры стартовые, не оптимизированные. Конфигурация описывает алгоритм, но сама по себе не является торговым роботом.

## 1. Вселенная
Получать distinct TICKER из исторических снимков FUTOI за каждый день. Не использовать сегодняшний список для прошлых периодов. Семейство FUTOI и конкретная торговая серия — разные сущности. Выбирать серию по объёму предыдущего торгового дня, фиксировать на сессию. После смены серии заново накопить 20 ценовых баров. Последние два торговых дня до экспирации исключить. Полный текущий список инструментов не подтверждён.

## 2. Время и качество
Хранить observation_time, publication_time и available_time. Для live available_time = время фактического получения; для истории — документированное время доступности с учётом задержки доступа. Все joins backward-asof по available_time. Не использовать значение, опубликованное после решения. Максимальная давность снимка 10 минут. Обе группы должны быть из одного пакета. Пропущенные пакеты и противоречия логировать. Проверить short sign, POS = long - short_magnitude, сумму лонгов и шортов. При нулевом знаменателе признак отсутствует, а не равен нулю.

## 3. Уровни
Бары 5 минут. U/D = максимум high / минимум low последних 12 завершённых баров, без текущего. ATR20 Wilder по завершённым барам; первичное значение — среднее 20 true ranges. Буфер max(2*tick_size, 0.1*ATR). Не переносить диапазон между сессиями и сериями. При событии уровень и ATR фиксируются.

## 4. FUTOI-признаки
S = abs(POS_SHORT), L = POS_LONG. OI = L_FIZ + L_YUR. N_FIZ = L_FIZ-S_FIZ. Изменение OI = log(OI_now/OI_reference). Изменение стороны = (side_now-side_reference)/OI_reference. Изменение N_FIZ для B3/B4 измерять в контрактах, отдельно сохранять нормированную величину. Reference — последний доступный снимок на момент decision_time минус 15 минут. Сохранять фактический интервал. Перцентили строить по прошлым 60 торговым дням, текущий день не включать. Если истории недостаточно, перцентильный вариант не торгует.

## 5. Эксперимент B: продолжение
Лонг: предыдущее закрытие не выше U+b, текущее выше U+b. Шорт зеркально. B0: цена. B1: B0 и положительный рост OI. B2: B1 и рост OI выше p75. B3: B1 и знак изменения N_FIZ совпадает с направлением. B4: B1 и знак противоположен. Нулевое изменение не относится ни к B3, ни к B4. Вход после закрытия бара, по первой исполнимой котировке после времени решения. Стоп 1 ATR, тейк 2 ATR от фактического входа. Закрытие бара внутри зафиксированного диапазона вызывает выход после закрытия. Лимит удержания 60 минут, без переноса через конец сессии.

## 6. Эксперимент F: ложный пробой
После первичного закрытия за D-b или U+b заморозить диапазон. В следующие 3 бара искать закрытие выше D+b для лонга или ниже U-b для шорта. F0: только возврат. F1: к возврату шорты FIZ выросли после пробоя вниз / лонги FIZ после пробоя вверх; сравнить последний доступный снимок до пробоя и к возврату. F2: F1 и это изменение выше p75 исторических эпизодов, построенного только по обучающему прошлому с той же методикой интервала. Не смешивать этот порог с распределением обычных 15-минутных изменений.
F3: F2, затем в следующие 10 минут дождаться сокращения соответствующей стороны относительно снимка на возврате. Вход после публикации подтверждения, не по прошлой цене. Отменить ожидание при новом закрытии за исходным уровнем пробоя с буфером. В статистике добавить ценовой контроль, входящий в то же время, что F3, но без использования величины FUTOI. Это диагностический matched-control, не самостоятельный live-сигнал.
Стоп за экстремум эпизода с буфером. Для F3 экстремум обновлять до фактического решения, не использовать будущее. Если риск больше 1.5 ATR, пропустить. Тейк 2R, удержание 60 минут, выход в конце сессии. Один эпизод — максимум одна сделка на вариант.

## 7. Исполнение и риск
Каждый вариант тестировать отдельным портфелем. Покупка ask, продажа bid; комиссии и проскальзывание обязательны. При OHLC вход на следующем полном баре после решения, если последовательность стоп/тейк неизвестна — стоп первым. Гэп через стоп исполнить по первой доступной цене. Денежный риск контракта = расстояние до стопа / tick_size * tick_value плюс издержки. Размер = floor(0.001*capital / риск контракта). Проверять маржу и ликвидность. Совокупный открытый риск 0.5%, одна позиция на семейство; без усреднения. Сигналы одного времени обрабатывать в фиксированном алфавитном порядке и сохранять отказы.

## 8. Проверка
Сначала event study: forward returns, MFE, MAE через 15/30/60 минут. Затем сделки. Walk-forward 12/3/3 месяца, шаг 3 месяца; финальные 6 месяцев holdout не использовать для выбора. Удалять пересекающиеся окна событий на границах. Первое исследование — общие настройки, без подгонки каждого семейства. Стресс издержек x2. Для оценки неопределённости использовать блоки по торговым дням, сохраняя межинструментальную зависимость.

## 9. Выходные таблицы
universe: дата, семейство, выбранная серия, допуск, причина исключения.
events: идентификатор, направление, уровни, время события/решения, времена и значения снимков, признаки, горизонты доходности, MAE/MFE.
trades: вариант, фактические цены и времена, количество, стоп/тейк, причина выхода, комиссии, проскальзывание, net PnL, PnL в R.
summary: результаты по семейству/направлению/месяцу/варианту, число сделок, expectancy R, profit factor, drawdown и отличие от B0/F0.

## 10. Ограничения
Агрегированные позиции не раскрывают цены входа, плечо, ликвидации и личность участника. Нетто-позиции FIZ и YUR зеркальны, не считать их двумя независимыми подтверждениями. Числа лонгистов и шортистов нельзя складывать как уникальных участников. FUTOI относится к семейству, не обязательно к единственной торгуемой серии. Ни один фильтр заранее не считается прибыльным.
